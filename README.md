# For Monica, Always — interactive birthday website

A responsive, five-page digital love letter built with plain HTML, CSS and JavaScript. No paid services or frameworks required.

## Pages
- `index.html` — cinematic welcome and chapter navigation
- `story.html` — interactive relationship timeline (tap each milestone)
- `little-things.html` — what you admire about Monica and three clickable confession envelopes
- `adventures.html` — interactive future travel cards for Europe and Kenya
- `letter.html` — animated birthday letter, final reveal, birthday message and an inside-joke secret unlock

## Features
- Real portrait and travel photos stored locally in `assets/`
- Scroll reveals, subtle photo zooms, hover transitions and letter reveal animation
- Clickable timeline milestones, confession envelopes and future destination cards
- Final birthday surprise and playful secret phrase unlock
- Responsive mobile layout and reduced-motion accessibility support
- No autoplay audio, external APIs, paid services or build tools

## Publish free with GitHub Pages
1. Create a public GitHub repository (for example `for-monica`).
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**. Under Build and deployment choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the URL and test every page on mobile before sharing.

The site itself and the two supplied photos are bundled locally. Google Fonts are optional enhancements and require internet; fallback fonts will work without them. The site is public when hosted on GitHub Pages, so do not add sensitive private information. The secret unlock is playful, not secure access control.
